## 1. What this project is

**telltale** measures "AI-writing tells" — lexical, phrasal, punctuation, syntactic/rhetorical,
structural, and statistical habits — in business/academic prose generated by Claude models, scored
against a versioned, extensible registry so new tells can be inventoried and the whole corpus
deterministically re-scored forever. Repo: private GitHub `markpaik/telltale-benchmark`, branch
`main`. Local root: `/Users/markpaik/Projects/benchmarks/opus5/`.

Core design commitments (Mark's non-negotiables — do not relitigate):
- **Evidence-first judging, no ratings ever.** The LLM judge only extracts verbatim spans and
  answers binary criteria questions; code verifies quotes against source, enforces criteria,
  computes every count and verdict. (Origin: Mark's central-tendency concern about LLM judges.)
- **Deterministic scoring**: pure function of (corpus bytes, registry bytes, judge cache).
  `report --verify` must always pass on an untouched run.
- **Isolation-gated generation**: every generation batch is gated by a live probe battery proving
  no CLAUDE.md/skills/MCP/tools reach the session (Mark's global CLAUDE.md loads a writing-voice
  skill that strips AI tells — contamination would invalidate everything).
- **Honest statistics**: bootstrap CIs, Wilson intervals, minimum-evidence flags; the scorecard
  never claims separation unless the CI excludes zero.
